# 🔍 LLM Fingerprint

**Authorship Attribution & Stylometric Fingerprinting for AI-Generated Text**

A research-grade, end-to-end machine learning pipeline that identifies **which Large Language Model wrote a given piece of text** — Gemma, Llama, Mistral, Phi-3, or Qwen — using fingerprint-preserving NLP, multi-level feature engineering, and a hybrid stacked ensemble.

Not "is this AI?" — but **"which AI?"**

## 📌 Overview

Modern AI detectors mostly answer a binary question — human vs. AI. This project goes a level deeper: given a block of AI-generated text, it predicts the **specific source model** behind it.

To do this reliably, the project builds its own controlled benchmark dataset (rather than reusing generic AI-text corpora), designs a **fingerprint-preserving preprocessing pipeline** that deliberately keeps the stylistic signals traditional NLP throws away, engineers **four complementary feature families**, and combines everything through **feature fusion + a hybrid stacked ensemble** of classical ML models.

| Stage | Best Result |
|---|---|
| TF-IDF (standalone) | 65.00% |
| Character N-Grams (standalone) | 68.00% |
| Stylometric Features (standalone) | 67.00% |
| Semantic Embeddings (standalone) | 50.00% |
| **Feature Fusion + XGBoost** | **78.37%** |
| **Hybrid Stacked Ensemble (final model)** | **80.28%** |

## 🧠 Key Research Objectives

1. **LLM Authorship Attribution** — classify text generated by multiple known models (Gemma 2, Llama 3, Mistral, Phi-3, Qwen-Tiny).
2. **Stylometric Fingerprinting** — extract robust lexical, character-level, structural, and semantic features representing generator-specific writing style.
3. **Hybrid Modeling** — combine classical ML (Logistic Regression, Linear SVM, Random Forest, XGBoost) with feature fusion and stacked ensembling.
4. **Open-Set Detection (in progress)** — flag text from models *not* present in the training set.

## 🏗️ Pipeline Architecture

```
Human-written corpora (5 sources)
        │
        ▼
 Prefix Engineering  ──────►  standardized, tokenized prompt prefixes
        │
        ▼
 Controlled AI Generation  ─►  identical prefixes fed to 5 LLMs
        │
        ▼
 Dual NLP Preprocessing  ───►  fingerprint-preserving  vs.  traditional
        │
        ▼
 Multi-Level Feature Engineering
   ├── TF-IDF
   ├── Character N-Grams
   ├── Stylometric Features
   └── Semantic Sentence Embeddings (MiniLM)
        │
        ▼
 Classical ML  (Logistic Regression · Linear SVM · Random Forest · XGBoost)
        │
        ▼
 Feature Fusion  (SVD + normalization + concatenation)
        │
        ▼
 Hybrid Stacked Ensemble  (4 base learners → Logistic Regression meta-classifier)
        │
        ▼
 Evaluation  +  Streamlit Deployment
```

Local software engineering (streaming pipeline, YAML configs, checkpointing) was built in the **Antigravity IDE**; compute-heavy generation, embeddings, and experiments ran on **Google Colab**.

## 📊 Dataset

No public benchmark exists for this exact task, so the dataset was engineered from scratch with a strict control: **every model receives the exact same prompt**, so any stylistic difference in the output can be attributed to the model itself, not the topic.

**Source corpora used for prefix extraction:**

| Dataset | Domain |
|---|---|
| WikiText-103 | Encyclopedic / formal |
| CNN/DailyMail | Journalistic news |
| XSum | Abstractive summarization |
| Project Gutenberg | Literature |
| StackExchange | Technical / conversational |

**Target LLMs (generators):** Gemma 2 · Llama 3 · Mistral · Phi-3 · Qwen-Tiny

## 🧬 Feature Families

| Feature Family | Captures | Notes |
|---|---|---|
| **TF-IDF** | Vocabulary / lexical importance | Strong lexical baseline |
| **Character N-Grams** | Punctuation, spacing, capitalization, formatting | Strongest standalone family (68%) |
| **Stylometric Features** | Sentence length, lexical diversity, readability, structure | Highly interpretable |
| **Semantic Embeddings** | Contextual meaning (MiniLM, 384-dim) | Best used in fusion, not alone |

---

## 🤖 Models

| Model | Role |
|---|---|
| Logistic Regression | Fast, interpretable linear baseline |
| Linear SVM | Best on high-dimensional sparse features (Character N-Grams) |
| Random Forest | Captures nonlinear interactions (Stylometric features) |
| XGBoost | Strongest standalone classifier; base learner in the ensemble |
| **Hybrid Stacked Ensemble** | All 4 above combined via a Logistic Regression meta-classifier on fused features |

## 🚀 Getting Started

### 1. Clone & Install

```bash
git clone https://github.com/deepakc0523/llm_fingerprint.git
cd llm_fingerprint
pip install -r requirements.txt
```

### 2. Run the Pipeline

```bash
# Show all CLI options
python main.py --help

# Run the full pipeline: preprocessing → features → training → evaluation
python main.py --pipeline

# Run a single stage
python main.py --stage feature_engineering
```

### 3. Run the Streamlit Demo

```bash
streamlit run app/streamlit_app.py
```

This loads the trained fusion + ensemble pipeline and lets you paste in any text sample to get a live prediction of the source model, confidence score, per-model probability breakdown, and inference time.

### 4. Explore in Notebooks

Exploration notebooks and the full training workflow are available under `notebooks/`.

## 📈 Results Snapshot

- Fingerprint-preserving preprocessing consistently **outperformed traditional NLP preprocessing by ~9–12 percentage points** across every classifier tested.
- **Character N-Grams** were the strongest individual feature family — confirming that low-level stylistic habits (punctuation, spacing, capitalization) are highly diagnostic of model identity.
- **Feature fusion** (TF-IDF + Character N-Grams + Stylometric + Semantic) beat every standalone feature family without exception.
- The **Hybrid Stacked Ensemble** delivered the best overall result: **80.28% accuracy** across 5 candidate models.

A live prediction demo is available via **Streamlit**, returning the predicted model, confidence score, per-model probability breakdown, and inference time (~0.37s).
